# Submission checklist

## Technical
- [ ] Intelligent Contract is lint-clean
- [ ] Direct tests pass
- [ ] Integration/Studio test passes
- [ ] Failure paths tested
- [ ] No secrets committed
- [ ] Repository is reproducible

## Product
- [ ] Task creation works
- [ ] Requirements are clear
- [ ] Public evidence can be inspected
- [ ] Consensus produces a structured verdict
- [ ] Final state is visible

## Deployment
- [ ] Target GenLayer testnet confirmed from current official docs
- [ ] Contract deployed
- [ ] Contract address recorded
- [ ] Transaction/deployment evidence recorded
- [ ] Demo works from a clean browser session

## Contribution
- [ ] Current GenLayer contribution requirements rechecked
- [ ] Project explanation is factual
- [ ] Why GenLayer is necessary is clearly explained
- [ ] GitHub and demo links are valid
- [ ] Screenshots/evidence are authentic
- [ ] No copied implementation or misleading claims
- [ ] Final submission reviewed before sending

## Important
Passing this checklist is required before calling TaskArbiter submission-ready. Points are not guaranteed.
